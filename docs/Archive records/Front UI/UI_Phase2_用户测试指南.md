### 4.2 常见问题

**Q: 搜索框输入后没有反应？**
A: 搜索有 300ms 防抖，等待片刻后会自动触发。

**Q: 全选后数量不对？**
A: 全选只选择当前筛选结果，不是全部模组。

**Q: 已部署数量总是 0？**
A: 部署状态集成尚未完成（Phase 2 剩余 10%）。

**Q: 点击"添加模组"没反应？**
A: 导入对话框尚未实现（Phase 2 剩余 10%）。

**Q: 模组图标不显示？**
A: 测试数据没有真实图标，应该显示默认占位符。
