# UI 性能基线（2026-10-03）

本记录对应 `docs/HD2Mimnt 整体 UI 设计与开发执行计划.md` 的阶段 9，先记录可重复的后端查询与集合处理基线，不把它等同于真实窗口人工验收。

## 测试条件

- Windows 11，12th Gen Intel Core i5-12400F，12 逻辑处理器。
- .NET SDK 10.0.401，运行时 .NET 10.0.12，Release 构建。
- BenchmarkDotNet 0.15.8，`ShortRun`（3 次预热、3 次测量）。
- SQLite 基准数据集：可重复运行 1,000、5,000、10,000 条模组记录三档；现有 Search 基准固定覆盖 10,000 条。

## 结果

| 场景 | 平均耗时 | 托管分配 |
|---|---:|---:|
| 读取 10,000 条模组（`EmptySearch_ReturnAll`） | 98.665 ms | 11.72 MB |

应用启动约 8 秒后采样到的启动进程工作集约 116 MB、私有内存约 53.8 MB、累计 CPU 时间约 3.30 秒。该采样包含启动阶段，不能替代初始化完成后的空闲基线；后续人工验收需要在窗口稳定后重复采样，并区分主进程与子进程。

设置页接入后的 Debug 启动冒烟在约 8 秒时采样到主进程工作集约 181 MB、私有内存约 59.2 MB、累计 CPU 时间约 0.86 秒。该样本与前一条记录的构建和启动上下文不同，仅用于确认启动链可用，不用于宣称性能回归或达标。

备份/日志接入后的 Debug 启动冒烟在约 8 秒时采样到主进程工作集约 183 MB、私有内存约 141 MB、累计 CPU 时间约 2.45 秒；该次启动使用已有 100 条模组数据，包含图标和日志初始化，仍需用 Release 构建完成稳定空闲采样。

Release 启动冒烟约 10 秒时采样到主进程工作集约 178 MB、私有内存约 140 MB、累计 CPU 时间约 2.66 秒。该样本低于计划的 500 MB 工作集上限，但仍需长时间空闲、页面切换和大规模列表窗口测试。

Release 进程采样器完成一次约 296 秒、5 秒间隔、60 个样本的隔离数据目录采样：最大工作集 214.44 MiB，最大 Private Bytes 175.92 MiB，最大托管堆 20.54 MiB，累计 CPU 增量 9.641 秒。该次只覆盖启动后空闲进程，没有页面切换、滚动或批量部署操作，因此仅作为采样链和空闲资源上限记录，不能替代完整 UI 稳定性验收。

新增采样脚本的 10 秒冒烟（2 秒间隔）记录了 5 个样本；末个样本工作集约 173.4 MiB、私有内存约 136.2 MiB、累计 CPU 时间约 2.67 秒。脚本会记录操作系统、CPU、逻辑处理器、物理内存和 .NET SDK 版本，并输出 CSV/JSON；该结果只用于确认采样链和启动阶段数据格式可用。

诊断采样器验证：隔离数据目录下 Release 启动 10 秒、2 秒间隔记录到 `ManagedHeapBytes`；末次样本工作集约 168.5 MiB、私有内存约 132.0 MiB、托管堆约 2.38 MiB。该样本仍是启动阶段，不代表 5/30 分钟空闲曲线。

测量范围是仓储读取和结果物化，不包括 Avalonia 控件创建、图标加载、滚动和窗口绘制。该结果接近计划中 100 ms 的目标，因此阶段 9 仍需补充真实 UI 窗口下的滚动、切页、配置切换、工作集、私有内存和托管堆记录。采样脚本现在通过显式 `HD2MIMNT_METRICS_PATH` 诊断开关记录 `GC.GetTotalMemory(false)`，不会在普通运行中启动采样定时器。

## 重复执行

```powershell
dotnet run --project benchmarks\HD2Mimnt.Benchmarks\HD2Mimnt.Benchmarks.csproj -c Release -- --filter "*SearchBenchmarks.EmptySearch_ReturnAll" --job short

# SQLiteBenchmarks 默认覆盖 1,000/5,000/10,000 三档数据量
dotnet run --project benchmarks\HD2Mimnt.Benchmarks\HD2Mimnt.Benchmarks.csproj -c Release -- --filter "*SQLiteBenchmarks*" --job short

# 先构建 Release UI，再采集进程级 CPU/内存曲线；默认输出到系统临时目录
dotnet build HD2Mimnt.slnx -c Release --no-restore
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\measure-release-ui.ps1 -DurationSeconds 180 -SampleIntervalSeconds 5

# 可选：将 UI 测试数据与默认用户数据隔离；脚本会在 CSV/JSON 中合并托管堆采样
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\measure-release-ui.ps1 -DataDirectory .\artifacts\ui-perf-data -DurationSeconds 300 -SampleIntervalSeconds 5
```

基准执行使用临时 SQLite 文件，`GlobalCleanup` 会删除该文件。采样脚本默认写入 `%TEMP%\HD2MimntPerformance`；本次冒烟产物已删除，未保留临时副本。
