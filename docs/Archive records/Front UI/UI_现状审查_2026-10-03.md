# HD2Mimnt UI 现状审查（2026-10-03）

本报告对应执行计划阶段 0，记录当前仓库实际实现、服务复用关系、已知缺口和性能证据。源码审查范围为 `src/HD2Mimnt.UI`、`src/HD2Mimnt.Application`、`src/HD2Mimnt.Infrastructure` 和对应测试项目。

## 技术与边界

| 项目 | 当前结论 | 证据 |
|---|---|---|
| UI 框架 | Avalonia，目标框架 .NET 10 | `src/HD2Mimnt.UI/HD2Mimnt.UI.csproj` |
| 页面组织 | `MainWindow` 持有一次性创建的页面 ViewModel，四个一级页面用隐藏 TabItem 承载 | `MainWindow.axaml`、`MainWindowViewModel.cs` |
| 业务访问 | 页面通过 Application 服务访问模组、配置、部署、任务和设置，不直接访问 SQLite | `LibraryViewModel`、`ProfileViewModel`、`SettingsViewModel` |
| 大列表 | 模组、配置、配置详情、配置对比、任务列表使用 `VirtualizingStackPanel` | 各页面 `ItemsPanel` 定义 |
| 后台取消 | 搜索、配置加载、部署、清理和任务服务提供取消令牌 | 对应 ViewModel/Service 实现及回归测试 |
| Release 启动 | 主窗口进程可启动并保持响应 | 2026-10-03：启动后进程 `Responding=True`，标题为 `HD2Mimnt - Helldivers 2 Mod Manager`；启动采样约 Working Set 164 MiB、Private Bytes 129 MiB |

## 已确认的性能瓶颈与处理

- 原配置详情逐个读取模组；现改为 `IModRepository.GetByIdsAsync` 分块查询，避免 N+1 查询。
- 原部署目录递归枚举在调用线程执行；现放入 `Task.Run` 并受取消令牌控制。
- 模组库 ViewModel 构造和筛选结果计算不在 UI 线程执行。
- SQLite 基准支持 1,000/5,000/10,000 三档，Search 基准覆盖 10,000 条；Release 进程采样脚本记录 CPU、Working Set、Private Bytes 和显式诊断采样器提供的 Managed Heap。

## 未完成或无法由自动化证明的项目

- 当前仓库没有武器/怪物等 8,000 条真实选择器页面，因此不能把该项标记为完成。
- 尚未完成真实窗口高 DPI、10,000+ 滚动、空闲 5/30 分钟和托管堆曲线验收。
- 图像缓存中涉及 Avalonia 位图创建/保存的 Headless 测试仍未纳入通过统计。
- 部署/清理临界关闭、锁定文件恢复、备份恢复后的真实业务数据仍需要 Windows 窗口人工验收。
- 本轮桌面观察工具因无法写入其内核资源路径而不可用，因此没有取得截图、点击回放或高 DPI 窗口证据；上述启动数据仅作为进程级冒烟记录。
- UI 可通过 `HD2MIMNT_DATA_PATH` 指向隔离数据目录，开发工具测试数据使用 `HD2Mimnt Test ` 名称前缀并按此前缀清理；源目录还可通过 `HD2MIMNT_TEST_MOD_PATH` 指定并逐项删除，性能验收不必修改默认用户数据目录。
