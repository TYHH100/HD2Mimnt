## 三、技术问题和解决方案

### 3.1 已解决的问题

**问题 1：** Program.cs 入口点警告
```
warning CS8892: 方法"Program.Main(string[])"将不会用作入口点，因为找到了同步入口点"AutoGeneratedProgram.Main(string[])"。
```

**解决方案：**
```xml
<PropertyGroup>
  <GenerateProgramFile>false</GenerateProgramFile>
</PropertyGroup>
```

**问题 2：** ZipArchive Entry 未关闭导致异常
```
Entries cannot be created while previously created entries are still open.
```

**解决方案：**
在 GenerateRealisticHD2IRZipAsync 中确保所有 using 语句正确关闭 Stream：
```csharp
using (var stream = jsonEntry.Open())
using (var writer = new StreamWriter(stream, Encoding.UTF8))
{
    await writer.WriteAsync(GenerateSampleHD2IRJson());
    await writer.FlushAsync();
} // 确保 stream 关闭
```
