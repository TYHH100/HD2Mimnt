## 四、关键概念速查

### 4.1 核心术语

| 术语 | 定义 | 详细文档 |
|-----|------|---------|
| **LogicalMod** | 用户视角的统一模组对象，包含多个组件 | HD2IR_QUICKREF.md |
| **Component** | 模组的组成部分（HD2IR/Model/Texture/Audio） | HD2IR_QUICKREF.md |
| **PackageSource** | ZIP 归档包 | HD2IR_QUICKREF.md |
| **DeployableFile** | 可部署的文件 | HD2IR_QUICKREF.md |
| **FileOwnership** | 文件所有权记录 | HD2IR_QUICKREF.md |
| **DiffEngine** | 差异计算引擎 | HD2IR_PHASE2-3_COMPLETE.md |
| **ProfileLogicalMod** | Profile-LogicalMod 关联 | HD2IR_PHASE4_COMPLETE.md |

### 4.2 核心流程

| 流程 | 简要描述 | 详细文档 |
|-----|---------|---------|
| **导入流程** | ZIP → 分析 → 检测 → 构建 LogicalMod | HD2IR_PHASE1_COMPLETE.md |
| **部署流程** | LogicalMod → Diff → 提取 → 部署 | HD2IR_PHASE2-3_COMPLETE.md |
| **配置切换流程** | Profile → Desired State → Diff → 应用差异 | HD2IR_PHASE4_COMPLETE.md |

### 4.3 设计模式

| 模式 | 应用场景 | 详细文档 |
|-----|---------|---------|
| **Repository Pattern** | 数据访问抽象 | 所有 Complete 文档 |
| **Adapter Pattern** | 统一部署抽象（IDeployableModSource） | HD2IR_PHASE2-3_COMPLETE.md |
| **Strategy Pattern** | 不同部署方法（Copy/SymLink/HardLink） | 原有架构 |
| **Builder Pattern** | LogicalModBuilder | HD2IR_PHASE1_COMPLETE.md |
