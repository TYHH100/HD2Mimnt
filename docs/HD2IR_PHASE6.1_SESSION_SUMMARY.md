## 四、技术问题和解决方案

### 4.1 问题 1：Program.cs 入口点冲突

**现象：**
```
warning CS8892: 方法"Program.Main(string[])"将不会用作入口点，因为找到了同步入口点"AutoGeneratedProgram.Main(string[])"。
```

**原因：**
xUnit 模板默认生成 Program.cs，与我们自定义的入口点冲突

**解决方案：**
```xml
<PropertyGroup>
  <OutputType>Exe</OutputType>
  <GenerateProgramFile>false</GenerateProgramFile>
</PropertyGroup>
```

**经验：**
- xUnit 项目需要显式禁用自动生成的 Program
- 或者重命名为 MainProgram.cs

### 4.2 问题 2：ZipArchive Entry 未关闭

**现象：**
```
Entries cannot be created while previously created entries are still open.
```

**原因：**
在创建新 Entry 前，前一个 Entry 的 Stream 未关闭

**原始代码：**
```csharp
var entry = archive.CreateEntry("file.txt");
using (var stream = entry.Open())
{
    await writer.WriteAsync(content);
}
// Stream 未刷新，Entry 仍然打开

var nextEntry = archive.CreateEntry("file2.txt"); // 失败
```

**解决方案：**
```csharp
using (var stream = entry.Open())
using (var writer = new StreamWriter(stream))
{
    await writer.WriteAsync(content);
    await writer.FlushAsync(); // 显式刷新
} // 确保 writer 和 stream 都关闭
```

**经验：**
- ZipArchive Entry 必须完全关闭才能创建新 Entry
- 嵌套 using 确保正确的释放顺序
- 显式 FlushAsync() 确保数据写入

### 4.3 问题 3：测试文件生成超时

**现象：**
```
Command did not complete within its 120s timeout and was moved to the background
```

**原因：**
生成 2GB 测试数据需要 ~9 分钟，超过 120 秒超时

**解决方案：**
- 命令自动移到后台运行
- 通过 Read 工具监控输出文件
- 等待后台任务完成通知

**经验：**
- 长时间运行的命令会自动后台化
- 可以通过任务输出文件监控进度
- 系统会在完成时发送通知
