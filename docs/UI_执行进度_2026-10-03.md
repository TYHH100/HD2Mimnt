## 本轮完成

- 阶段 2：模组库从最新部署会话读取部署状态；模组删除同步清理部署记录；导入入口使用 Avalonia 文件选择器并复用 `ModService`；搜索防抖改为可取消的 `async` 流程；筛选/排序后台计算后再更新绑定集合。
- 阶段 3：新增配置文件页面，支持搜索、新建、复制、切换、重命名、删除和详情模组列表；切换后通过事件刷新模组库启用状态；删除当前配置时阻止危险操作。
- 阶段 3 对比功能：配置文件详情支持只读对比两个配置，展示共有、仅左侧、仅右侧和启用状态不同的模组，并支持差异筛选；对比结果使用虚拟化列表承载。
- 阶段 4：模组库接入部署方式选择、部署、清理、进度反馈和结果通知，使用现有 `DeploymentService`。
- 阶段 5：任务中心改为顶部入口打开的覆盖面板，读取 `TaskService` 运行任务和历史任务，支持取消运行中的任务。
- 阶段 6：新增设置页面，复用 `SettingsService` 和 `GameDetectionService`，支持游戏路径检测、部署方式、部署前检查、缩略图偏好、保存和恢复默认值。
- 阶段 6 设置完善：补充分类导航、主题/列表密度/动画设置、主题即时应用，以及图片缓存统计和清理入口；列表密度即时作用于模组库行间距。
- 模组库设置补齐：默认排序和默认筛选复用现有 `SettingKeys` 持久化，变化只作用于内存筛选结果，不触发数据库重载。
- 模组库筛选补齐：新增未部署统计、未部署筛选和一键清除筛选；不伪造当前后端无法可靠计算的冲突筛选。
- 配置状态性能：新增 `GetByIdsAsync` 分块读取接口，配置详情和对比只加载实际涉及的模组；配置切换旧请求会取消，避免旧结果覆盖新选择。
- 批量状态一致性：启用未加入当前配置的模组会自动加入并分配顺序；批量启用/禁用在一次 Profile 更新中提交。
- 开发工具随机启用状态改为一次批量配置更新，避免大数据验收时逐条读写 ProfileMods。
- 部署恢复边界：清理任一文件失败时保留部署记录和文件记录，避免失败后丢失重试依据；新增故障注入集成测试。
- 大目录响应：部署目录递归枚举放入可取消后台任务，模组列表项构造放入后台计算。
- 主题资源：深色/浅色主题提供统一表面、边框和文字动态资源，公共页面不再依赖固定深色中性色。
- 测试隔离：SQLite 测试程序集关闭类级并行，避免测试上下文的连接池清理互相影响；排除图像缓存测试的常规回归为 445/445。
- 阶段 7 基础页面：新增“更多”页，提供开发工具入口说明和版本信息；没有虚构未接入的外部工具功能。
- 阶段 8 基础体验：新增统一确认对话框、通知面板承载、删除确认、通知集合 UI 线程更新；主窗口改为只创建一次 ViewModel，避免重复事件订阅。
- 阶段 8 交互细节：补充 `Ctrl+F`、`Ctrl+A`、`Delete`、`Enter`、`Esc` 键盘行为，模组库/配置文件/任务中心空状态与错误状态，部署和清理确认及取消入口。
- 通知一致性：修复通知删除只更新 UI 而未更新服务队列的问题；普通通知到期后会从服务和面板移除，并支持通知操作按钮。
- 通知跳转：通知支持统一导航目标；游戏路径、配置文件缺失和部署前置条件失败时，可从通知直接跳转到设置、配置文件或模组库页面。
- 阶段 7 入口：更多页接入真实开发工具入口和性能基线信息，不再只显示“请使用顶部工具按钮”的说明。
- 阶段 7 外部工具：接入现有 `ExternalToolService`，更多页支持外部工具列表、添加、编辑、启用/禁用、删除确认、持久化校验和选择文件后启动。
- 阶段 7 插件管理：接入现有 `PluginService`，更多页支持插件列表、manifest 文件选择安装、启用/禁用、卸载确认和执行历史查看。
- 阶段 7 数据备份：新增 `BackupService` 和更多页备份面板，支持数据库/设置打包、备份列表、恢复确认、删除和恢复后的页面刷新。
- 阶段 7 日志诊断：新增文件日志提供者和日志面板，支持最近 500 行异步读取、导出；日志读取使用有界队列。
- 阶段 7 插件权限：安装前显示 manifest 权限请求，已安装插件支持权限逐项授予和撤销。
- 设置可靠性：设置文件写入失败会回滚内存状态并向 UI 返回失败，避免显示虚假的保存成功。
- 应用关闭边界：主窗口关闭前查询运行中任务，并在可能中断后台操作时要求明确确认。
- 下载取消边界：修复排队任务在后台启动后覆盖已取消状态的问题，并补充回归验证。
- 任务中心状态一致性：将单任务进度持久化改为串行写入，并在后台启动前检查取消状态，修复历史查询偶发为空的问题。
- 统一 Avalonia 依赖版本：Infrastructure、测试项目与 UI 使用 `12.0.3`，修复测试运行时类型版本冲突。
- 前后端对接优先：按旧项目的筛选列表选择语义校正模组库批量选择；全选和反选只作用于当前筛选结果，隐藏筛选项的选择状态保持不变，并已补充 ViewModel 回归测试。
- 模组库入口对接：顶部“更多操作”已接入刷新、清除筛选和清空选择命令；移除没有实际状态或后端行为的列表/网格切换按钮，避免保留假交互。
