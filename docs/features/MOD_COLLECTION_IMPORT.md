# 散装文件夹合集导入

## 使用场景

模组以散装文件夹（或只套了一层同名目录的压缩包）分发，外层本身不是模组：根目录没有 `manifest.json`，每个直接子目录各自是一个模组，各自带清单与选项目录。典型例子是把同一角色的多套装甲替换打包成一个“系列”。

旧行为会向下找到第一份清单，把其中一个子模组当成整个模组导入，其余子模组被静默忽略。现在这类输入按**一个模组**入库，配置页按两级显示：一级是子模组组件，点进去二级配置该子模组自己的选项；与 HD2IAS 组件包共用同一套两级选项页（见 [HD2IR 接入](HD2IR_INTEGRATION.md)）。

## 识别规则

- 外层目录（或压缩包解出目录）根目录已有 `manifest.json` → 普通模组，不按合集处理。
- 外层没有清单，且直接子目录中至少 2 个各自带 `manifest.json` → 合集，根目录不变。
- 外层只有一个目录、该目录本身不是模组、其中至少 2 个子目录带清单 → 该目录是合集根（压缩包常见的同名包裹层）；库条目名仍取导入的压缩包/文件夹名。
- HD2IR/HD2IAS 识别优先；只有 1 个带清单子目录时不按合集处理，保持“向下找一层清单”的既有行为。

## 嵌套压缩包

压缩包解压后整棵树都没有清单时，外层不是模组，管理器会先展开其中的嵌套压缩包再识别：

- 只处理压缩包导入的临时解压树，根目录与一层子目录里的压缩包（含 `.zip`/`.7z`/`.rar` 等）解到同名的同级目录（重名追加 ` (2)`），成功后删除原压缩包；包内唯一包裹目录会拍平。只展开一轮，内层包再套压缩包请先解包，避免误展开已展开模组自带的素材包。
- `.hd2irpack.zip` 不展开：HD2IR 识别按文件名判断，展开成目录会丢失证据；HD2IR 检测本身也优先于本步骤，其按包分组的组件不会被合并。
- 展开出的目录没有作者清单，只要直属补丁文件就可作为合集组件（默认启用、整个目录作为一个可启停组件）；普通散装目录没有清单时**不会**因此改判为合集，仍按原有清单推断规则处理。
- 只有一个内层包时通常不算合集：解压树拍平后按普通模组导入（补丁落到模组根）；根目录还有其它文件、无法拍平时仍生成单组件合集，保证补丁可部署。根目录自带补丁时也不按合集处理，避免根级补丁在组件选择中被丢弃。
- 展开始终不修改用户源文件夹：文件夹导入、其他管理器迁移走原有流程。

## 生成的清单

- 库条目名 = 导入的文件夹名或压缩包名（去掉扩展名）；描述、作者、版本按第一个子清单补齐。
- 一级组件：每个子目录一个；组件名优先取子清单 `Name`，多个子清单名称相同或为空时改用目录名，避免组件标题重复。描述与预览图取子清单 `Description`/`IconPath`，清单没写图片时取子目录根级预览图。
- 二级选项：子清单是 V1 时保留每个选项的名称、描述、默认启用、子选项和图片，`Include` 与图片路径加子目录前缀（如 `RS-100.../本体`），越界或绝对路径丢弃；子清单是 Legacy 时转换为一个组件卡片 + 每个互斥目录一个子选项；子清单没有选项声明时整个子目录作为一个可整体启停的组件。
- 外层封面：使用外层根目录图片；根目录没有图片时卡片留空，不回退到组件或选项图片。组件和选项仍显示各自的预览图。
- 生成的选项树写入管理器自有 `.hd2mimnt-options.json` 并投影到数据库清单；作者子清单保持原字节。数据库清单缺失时从该 JSON 回填，两级结构不会丢。

## 文件与部署

- 子目录内容原样复制到库内副本；部署复用现有补丁展开（`PatchDeploymentPlanner`）：只扫描选中组件/选项目录直属补丁并按资源前缀重新编号，未选组件不部署；缺失的 `.stream`/`.gpu_resources` 不部署（2026-10-25 起不再生成 0 字节占位，游戏加载占位会崩溃）。
- 重复导入仍按完整内容判重；生成的选项 JSON 不参与重复判重指纹，文件夹与压缩包内容一致时保持同一 Hash 语义。

## 边界

- 合集不是“多个模组分别入库”：库中只有一个条目；需要独立条目时请分别添加各个子目录。
- 包内自带根级作者清单的合集仍按普通模组处理，不会二次改写作者选项。
- 子清单损坏时跳过该子目录（若是展开出的内层包且带直属补丁，则按无清单组件处理）；可用的带清单子目录少于 2 个且没有展开出的补丁包时回退普通导入行为。
- 更新/替换模组时重新生成清单与 `.hd2mimnt-options.json`，不做增量合并。

## 验证边界

`ModCollectionImportTests` 使用真实文件与 SQLite 覆盖散装文件夹、包裹压缩包、Legacy/无选项子模组、嵌套压缩包展开（多内层补丁包成组件、单内层包拍平、根清单模组保留包内压缩包、普通散装补丁目录不改判合集）、重复导入、部署选择、数据库清单缺失回填与单包裹模组回归；`ModOptionExpanderUiTests` 的 Headless 用例验证导入后配置页一级组件进入二级选项并持久化。用户 2026-10-18 提供的真实 3 装甲系列样本（18 个选项，部分选项图片缺失）已确认分组、映射路径与缺图占位正确；封面规则于 2026-10-21 调整为根目录无图片时留空。用户 2026-10-27 提供的“外层 zip 内含 5 个 RAR 补丁包”真实样本（RAR5）已验证展开为 5 个组件、补丁文件与临时目录清理正确。文件级与 Headless 通过不代表游戏内兼容性已验证。
